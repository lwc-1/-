# 简历项目描述

## 项目名称

面向办公文档场景的大模型自动化评测系统

---

## 简历版本（推荐直接使用）

**项目描述：**
面向办公文档处理场景（信息抽取、文档摘要、格式转换、多轮上下文），设计并实施端到端的大模型自动化评测方案，覆盖评测集构建、机评脚本开发、数据分析和报告生成全流程。

**项目职责：**
- 设计 L1-L3 分层评测框架，覆盖信息抽取、文档摘要、格式转换、多轮上下文 4 类办公文档处理能力，共 12 个 L3 评测子领域
- 构建 30+ 条中文测试用例集，支持单轮和多轮对话场景，并为每条用例定义参考要点、期望格式和约束条件
- 设计指令完成度、内容准确性、格式正确性、完整性、上下文一致性 5 个评分维度及 1-5 分量化评分标准
- 基于 Python + OpenAI-compatible API 开发自动化评测脚本，实现被测模型调用、规则校验（JSON 合法性、关键词检测、长度校验）、LLM-as-Judge 自动评分
- 对低分用例进行 Bad Case 归因分析，定位格式不符、信息遗漏、多轮上下文丢失等问题，并输出针对性优化建议
- 支持人工抽检模板自动生成，抽取 30% 用例对比机评与人评结果，验证评测系统可信度
